## 🚀 QUICK START GUIDE

### 1️⃣ **Activate the Theme** (2 minutes)
```
WordPress Admin → Appearance → Themes → Activate "Foodica Child"
```

### 2️⃣ **Set Homepage** (1 minute)
```
1. Pages → Add New → Title: "Home" → Publish
2. Settings → Reading → Select "A static page" → Homepage: "Home"
3. Edit Home page → Template: "Front Page" → Update
```

### 3️⃣ **Add AdSense Codes** (5 minutes)
```
1. Open ADSENSE-CODES.html
2. Get your Publisher ID from AdSense
3. Create 3 ad units in AdSense
4. Appearance → Widgets → Add Custom HTML to each slot
5. Paste codes with your IDs
```

### 4️⃣ **Create Content** (30 minutes)
```
1. Create 4 categories: Breakfast, Lunch, Dinner, Desserts
2. Create 6 recipe posts with featured images
3. Tag 3 posts as "Featured" for slider
4. Publish all posts
```

### 5️⃣ **Test** (10 minutes)
```
1. Visit homepage
2. Check mobile responsiveness
3. Verify ads show (or placeholders)
4. Test all links
5. Run PageSpeed test
```

**Total Setup Time: ~50 minutes**
