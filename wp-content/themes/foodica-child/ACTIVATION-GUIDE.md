## ❓ TROUBLESHOOTING

### "Homepage looks like blog posts"
→ Did you set the "Home" page as homepage in Settings → Reading?
→ Did you select "Professional Homepage" template when creating the page?

### "No slider showing"
→ Create "Featured" category (Posts → Categories)
→ Assign 5 posts to this category
→ Make sure posts have featured images

### "Categories show gray boxes"
→ This is normal if posts don't have images yet
→ Add featured images to your posts
→ Or install "Categories Images" plugin to add category thumbnails

### "Styles look broken"
→ Hard refresh browser: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
→ Clear any caching plugins (WP Super Cache, W3 Total Cache)
→ Deactivate/reactivate child theme

### "Functions missing"
→ Make sure parent Foodica theme is INSTALLED (doesn't need to be active)
→ Verify child theme is activated (not just installed)
